# Orca-Kernel

基于 Orca 的有限范围二开：复用会话、Worktree、任务、消息与恢复能力，补充任务契约、执行准入和成果验收。当前只推进 v0.1。

本仓库目前保存项目执行依据和接手记录，尚未引入 Orca 源码，未实现 Kernel 功能。GitHub 上它是私有独立仓库，不是 `stablyai/orca` 的 Fork；现有 LICENSE 不替代将来引入上游时应保留的许可与来源。
